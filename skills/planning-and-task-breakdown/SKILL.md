# Planning & Task Breakdown

Use for every non-trivial task.

## Procedure
- Inspect repository structure and relevant files.
- Restate the objective and acceptance criteria.
- Identify dependencies and risks.
- Break work into ordered, verifiable steps.
- Define the local test plan.
- Ask only unresolved questions that materially change the implementation.
- Explicitly ask whether to run local tests after implementation when relevant.

## Exit condition
Do not enter implementation until the plan has enough information to execute without
repeated confirmation.
