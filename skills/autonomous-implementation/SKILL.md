# Autonomous Implementation

After plan approval, work like a senior developer.

Rules:
- Edit files directly.
- Run safe development commands without asking again.
- Implement end-to-end rather than stopping at scaffolding.
- If compilation/build/test fails, inspect the failure, fix it, and rerun.
- Keep a short internal task checklist and mark items complete only after verification.
- Do not ask "should I continue?" for work already covered by the approved plan.
- Stop only at a real boundary: missing required input, unavailable external dependency,
  unsafe production action, or unresolved ambiguity.
