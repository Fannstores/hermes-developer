# Hermes Developer Skills Index

Recommended baseline skills:
1. Planning & Task Breakdown
2. Autonomous Implementation
3. Test & Verify
4. Debugging & Recovery
5. Code Review
6. Security & Secrets
7. Git Workflow
8. Web Research
9. Browser Testing
10. Dependency Audit
11. Architecture
13. Telegram Operations
14. Documentation

These are deliberately modular so Hermes can select only the skills relevant to a task.
They are inspired by current agentic software-engineering practices: plan-first execution,
local verification, debugging loops, code review, security, browser/tool use, and skills
that encode team-specific workflows.

- `SKILLS/ERROR-RESOLUTION.md` — root-cause debugging, regression protection, and autonomous error resolution.
