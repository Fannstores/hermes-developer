# Developer Telegram Rooms

Only two visible developer rooms are required.

## 1. Developer Planning / Discussion
Purpose:
- task discussion
- repository findings
- planning questions
- plan approval
- scope/acceptance criteria

Hermes may ask questions here before plan lock.

After plan lock, routine implementation confirmation is not requested.

## 2. Developer Delivery / Completed
Purpose:
- completed project delivery
- test evidence
- commit/hash
- known limitations
- deployment/verification result

Execution is not narrated into a separate room.
