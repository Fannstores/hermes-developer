# Hermes Developer V2 BEST

A high-autonomy developer operating profile for Hermes.

Core loop:
TASK -> INSPECT -> PLAN -> LOCK -> EXECUTE -> TEST -> FIX -> VERIFY -> DELIVER

The operator answers questions during planning, including whether local testing is required. Once the plan is approved, Hermes executes end-to-end without routine confirmation spam.

Included:
- autonomous developer workflow
- Git commit/repository discipline
- testing and self-repair loop
- code review and security skills
- frontend/web design skill
- MCP discovery/usage policy
- anti-hallucination evidence rules
- two-room developer workspace: Planning/Discussion + Delivery/Completed

This package is a developer profile/workflow, not a claim that every external MCP or GitHub write integration is available. Hermes must verify capabilities before using them.
