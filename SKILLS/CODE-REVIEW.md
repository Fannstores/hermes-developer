# Code Review Skill

Before delivery, inspect:
- correctness
- security
- error handling
- edge cases
- race/concurrency issues
- API contracts
- data validation
- logging/secret exposure
- maintainability
- dead code
- accidental scope creep
- tests for changed behavior

For UI:
- accessibility
- responsive behavior
- component reuse
- visual consistency
- loading/error/empty states

Review the final diff, not just the files edited.
