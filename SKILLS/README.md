# Hermes Developer Skills

This directory defines the skill policy for a free/open-source, production-oriented developer agent.

Recommended skill families:
- planning-and-task-breakdown
- incremental-implementation
- debugging
- TDD/testing
- code-review
- security/AppSec
- API design
- Git/repository operations
- frontend design
- browser testing
- documentation
- context engineering
- source-driven/doubt-driven development

Priority:
1. Repository/project rules
2. Hermes system rules
3. Task-specific skill
4. General best practice

Skills must never invent evidence or override safety boundaries.
